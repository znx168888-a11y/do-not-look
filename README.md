# DO NOT LOOK

Interactive Three.js gallery exploring gaze and surveillance.

## Controls

- WASD to move and mouse to look around.
- Hold Space to raise your view to the peephole.
- Approach the peephole and center it in the crosshair to see the live overhead view.
- Press R to Look Closer and switch to the local webcam grid.
- Seven white plaster busts turn to follow the visitor.

Webcam access requires browser permission and HTTPS or localhost. Video stays in the browser.

## Run locally

```sh
python -m http.server 8000
```

Visit http://localhost:8000.

## Publish with GitHub Pages

Serve the main branch from the repository root in Settings > Pages.
